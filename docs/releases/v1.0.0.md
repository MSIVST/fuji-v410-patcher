# FujiV410Patcher x86 v1.0.0

Initial public release.

## What This Does

- Auto-advances past the startup warning screen.
- Applies the MP3 fresh-open `0 ms` seek-path fix for the observed end-of-track cutoff.
- Changes the map-update reminder interval from 28 days to 365 days.
- Updates the visible reminder option text from `28 Days` to `1 Year`.

## What This Does Not Include

This release does not include official Garmin/Suzuki firmware, patched firmware, maps, unlock files, or extracted firmware payloads. Users must provide their own official Suzuki Garmin Fuji v4.10 `GUPDATE.GCD`.

## Safety

Firmware modification can brick hardware. Keep stock v4.10 recovery media available before testing.
