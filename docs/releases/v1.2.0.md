# Fuji v4.10 Patcher v1.2.0

This release adds the complete media and artwork patch set:

- Ogg/Vorbis playback and unsupported-format guards.
- WMA and progressive JPEG cover-art fixes.
- JPEG artwork in supported ID3v2.3/v2.4 MP3 files.
- Startup-warning, MP3 end-of-track, and map-reminder fixes.
- Strict stock-firmware verification and safer atomic output writing.

JPEG is supported; PNG artwork is not supported by the unit. The package
contains no Garmin/Suzuki firmware or patched `GUPDATE.GCD`.

See `Technicals.md` for compatibility, hashes, implementation, verification,
and recovery details.
