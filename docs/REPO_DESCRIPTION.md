# Repository Description

Short description:

```text
Unofficial patcher for official Suzuki Garmin Fuji v4.10 GUPDATE.GCD files. No firmware included.
```

Longer forum/GitHub blurb:

```text
FujiV410Patcher is an unofficial Windows/Python patcher for official Suzuki Garmin Fuji v4.10 GUPDATE.GCD firmware files. It does not include Garmin or Suzuki firmware. Users provide their own official firmware, the tool verifies the stock file, applies small documented byte patches, fixes visible checksum blocks, and writes a patched output file.

Current patches auto-advance the startup warning screen, fix the observed MP3 end-of-track cutoff by matching the seek/resume playback path, and extend the map update reminder from 28 days to 365 days.
```
